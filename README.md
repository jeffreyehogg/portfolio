# Jeff Hogg Portfolio

Personal software engineering portfolio built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion, deployed on Vercel.

## Development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm lint
pnpm typecheck
pnpm build
```
