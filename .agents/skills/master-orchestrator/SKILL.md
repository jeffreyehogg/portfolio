## 5-Phase Execution Workflow

### Phase 1: Self-Discovery & 4 Parallel Audits
1. **Automated Discovery**: Detect tech stack, domain archetype, primary user outcomes, and dynamic data health.
2. **Dispatch 4 Parallel Sub-Agents**:
   - `Sub-Agent 1`: Storytelling, Mission Clarity & Problem/Solution Contrast.
   - `Sub-Agent 2`: UX/UI Craft, Obsidian/Glass Aesthetics, Anti-AI-Slop, Mobile Ergonomics ($\ge 44\text{px}$).
   - `Sub-Agent 3`: Feature Ideation & Zero-Barrier Interactive Tool Suite (live sandbox, calculators, matrices).
   - `Sub-Agent 4`: Technical SEO, Core Web Vitals, WCAG AA Accessibility & Code Health.

### Phase 2: Synthesis & Autonomous Approval Gate
- Synthesize findings into a **Master Overhaul Blueprint** artifact.
- Autonomously approve the blueprint against high-craft visual standards, feature innovation, and performance.

### Phase 3: Partitioned Autonomous Implementation (Zero-Collision)
- **Track A**: Foundation, design tokens, error/loading/not-found boundaries, navigation with mobile drawer.
- **Track B**: Dedicated feature engines in `components/features/<name>/` with Web Worker INP protection.
- **Track C**: Data layer hardening, connection pooling singletons on `globalThis`, and modal a11y.
- **Track D**: View synthesis using Asymmetric Bento layouts and JSON-LD structured schemas.

### Phase 4: Social Assets & Documentation
- Ensure 1200×630 OpenGraph assets and update `README.md` with domain architecture and benchmarks.

### Phase 5: Verification, Cleanup & Handover
- Run native build and lint commands (`build` exits with code 0, `lint` exits with code 0).
- Stop background tasks, check `git status`, commit (`feat(<scope>): ...`), push, and deliver executive report.
- Adhere to the **Universal Continuous Learning Protocol** to record portable discoveries.
