Kingdom Connect

Kingdom Connect is a digital platform designed to bridge the gap between church needs and volunteer service. It empowers churches to post service opportunities and fundraising needs, while providing a seamless way for Christians to find where they fit in the body of Christ.

Features

Service Board: A public board of volunteer opportunities (e.g., "Homeless Breakfast", "Backpack Stuffing") filtered by category (Food, Labor, Supplies).

Kingdom Fund: A crowdfunding interface for specific church needs (e.g., "New Outreach Van"), showing real-time progress bars.

Volunteer Dashboard: A personalized dashboard for users to track their upcoming commitments and see their service impact.

Admin Dashboard: A secure portal for ministry leaders to create new events, launch funds, and manage signups.

Authentication: Secure user accounts powered by Clerk (Sign In/Sign Up).

Real-time Updates: Interactive signups and donations backed by a robust database.

Tech Stack

This project is built with the modern "Pro" Next.js stack, optimizing for performance, scalability, and developer experience.

Framework: Next.js 14+ (App Router, Server Components, Server Actions)

Language: TypeScript

Styling: Tailwind CSS

Authentication: Clerk

Database: Neon (Serverless PostgreSQL)

ORM: Drizzle ORM

Deployment: Vercel
